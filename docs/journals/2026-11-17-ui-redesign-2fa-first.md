# 2026-11-17 - Campsite light redesign and 2FA-first UX

Implemented the 4-phase UI redesign and 2FA-first workflow overhaul following the updated `DESIGN.md` (Campsite light system).

## What

- **Phase 1 (Campsite design tokens & reskin):** Replaced dark/azure CSS variables in `app/globals.css` with semantic Campsite light tokens (`canvas` `#fffdf9`, `surface` `#ffffff`, `inset` `#f5f5f5`, `line` `#f0f0f0`, `ink` `#171717`, `ink-2` `#525252`, `muted` `#737373`, `faint` `#a3a3a3`, `accent` `#ff6b1a`, `accent-wash` `#fef3c7`, `accent-ink` `#451a03`, `danger` `#ef4444`, `success` `#22c55e`), added WCAG-compliant `:focus-visible` outlines, loaded Inter weights 400/500/600 in `app/layout.tsx`, updated PWA theme colors in `app/manifest.ts`, swapped dark-only `developer-icons` (`GitHubLight`, `AppleLight`, `XLight`, `VercelLight`) and `resend-white` PNG for light-background variants, updated `CLAUDE.md`, and reskinned all UI primitives, modals, pickers, and `/docs` pages with unified Vietnamese copy.
- **Phase 2 (`authenticator` type & Codes home):** Added `supabase/migrations/0003_add_authenticator_type.sql` and registered `authenticator` across `VaultItemType`, Zod `authenticatorSchema`, `TYPE_ICON`/`TYPE_LABEL`, `FIELDS_BY_TYPE`, `searchItems`, and `hasTotp`. Built `lib/ui/codes.ts`, `lib/ui/use-now.ts` (single shared 1s ticker pausing while hidden), `lib/ui/use-tab.ts`, `components/code-row.tsx` (tap-to-copy row, `CountdownRing` shared with `totp-display.tsx`, `<= 5s` warning + `"Tiếp theo"` code preview, optional privacy blur), `components/codes-screen.tsx` (pinned-first A-Z list, desktop keyboard navigation, empty state), `components/bottom-nav.tsx`, and `components/toast.tsx`.
- **Phase 3 (Google Authenticator import & unlock/auto-lock UX):** Implemented a zero-dependency pure TS protobuf reader in `lib/ui/ga-migration.ts` for `otpauth-migration://` exports, added continuous multi-QR camera + multi-image support to `components/qr-scanner-modal.tsx`, and built `components/import-ga-modal.tsx` (batch progress, duplicate pre-uncheck, HOTP/MD5 skipping). Replaced `lockOnHidden` boolean with `lockOnHiddenAfterMs` (default 60s, legacy migration in `loadSettings`), added `hideCodes` toggle, updated `useAutoLock`, and added one-shot automatic biometric prompt on `LockScreen` mount.
- **Phase 4 (Vault list & master-detail):** Replaced card grid + drawer with `components/vault-screen.tsx`, `components/vault-row.tsx` (inline quick copy for username, primary secret via `primarySecretField`, and TOTP), `components/type-chips.tsx`, `components/filter-popover.tsx`, `components/item-detail.tsx`, `components/item-avatar.tsx`, and mobile full-screen `components/detail-drawer.tsx` with history back support. Deleted superseded `item-card`, `item-grid`, `item-card-skeleton`, `filter-bar`, and `top-bar`. Updated `/docs/*` and `docs/security-model.md`.
