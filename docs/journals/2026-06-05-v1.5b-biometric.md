# 2026-06-05 - v1.5b: WebAuthn biometric unlock

Shipped the second half of v1.5: optional, per-device biometric unlock
(Face/Touch/Windows Hello) via the WebAuthn PRF extension. Master password stays
the root of trust and the always-available fallback. Brainstorm -> plan -> cook
-> review -> commit on `origin/dev` (`c4e6771`).

## How it works
- **Enroll** (Settings, prompts master once): verify master via `unlockWithMaster`,
  derive authSecret, export the in-RAM DEK; WebAuthn `create()` a platform
  credential with the PRF extension, check `prf.enabled`, `get()` with a random
  32-byte salt to obtain the PRF output, import it as an AES-GCM key, and
  `encryptJSON({ dek, authSecret })` into IndexedDB. Ciphertext-only on disk.
- **Unlock**: `get()` the PRF output (same salt) -> unwrap -> import DEK ->
  `signInVault(authSecret)` -> setUnlocked. Any failure resets to master.
- **Change master** rotates authSecret, so it clears the biometric bundle (stale)
  and asks the user to re-enable.

## Decisions
- **Raw WebAuthn, no dependency** - there is no server attestation to verify; this
  is a local-only key-derivation use, so the challenge is a local random and the
  PRF output is the only thing that matters.
- **Prompt master at enroll** instead of stashing authSecret in RAM all session -
  cleaner, and a deliberate confirmation.
- **Feature-detect PRF** and hide the option where unsupported (Chrome 116+/Edge,
  Safari 18+, Firefox limited). Per-origin + per-device binding.

## Review caught a real bug
A code review found a **Critical**: `enableBiometric` wrapped the typed master
password WITHOUT verifying it, so a typo silently enrolled a bundle whose
authSecret was wrong and could never sign in. Fixed by verifying via
`unlockWithMaster` before wrapping. Also fixed: clear biometric on the
indeterminate change-master branch (H2), IndexedDB resolve on `tx.oncomplete`
for write durability (M1), SSR guards in the IDB helpers (M2), an `rpId` mismatch
check at unlock (M3), and best-effort scrub of the PRF output / raw DEK bytes (L1).

## Verification
`tsc` clean, `guard` clean (biometric layer is client-only), `build` passes.
Zero-knowledge intact: nothing extra reaches Supabase; the IndexedDB record is
ciphertext + public salt/credentialId only, decryptable only via a fresh PRF eval
against the device authenticator. The biometric round-trip itself needs a
PRF-capable browser + platform authenticator to test manually.

## v1.5 complete
v1.5a (TOTP) + v1.5b (biometric) done. Remaining for v2: nonce-based CSP (drop
